# Lynx Plumbing homepage recreation

A self-contained, responsive recreation of the supplied homepage, with no Envato toolbar or marketplace branding. Built with plain HTML, CSS, and JavaScript. Images and fonts are local.

## Preview

Open index.html directly, or serve this folder:

    python3 -m http.server 4817 --bind 127.0.0.1

Then visit http://127.0.0.1:4817.

## Behavior

Navigation links lead to homepage sections. Service, project, and article details open dialogs. FAQs expand and collapse. The booking form validates fields and stores a demonstration request in browser localStorage. The newsletter form stores a demonstration email locally. Neither form sends data or creates an actual booking. Connect your own backend before using the forms in production.

The reference business name, contact information, imagery, and example testimonials remain demo content. Supporting pages from the original template kit are represented here by homepage sections and detail dialogs.
